# if-ai

Write pull request checks in plain English. Evaluate a PR body, its complete text diff, or every changed file with [Jev](https://typesafe.ai), and require a minimum confidence to pass.

Implementation is in progress. The accepted scope is in [docs/mvp.md](docs/mvp.md), with [API research](docs/research/jev-api.md) and [related projects](docs/research/overlap-and-mvp.md).
